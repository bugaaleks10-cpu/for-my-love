САЙТ-ДЛЯ-НЕЁ

1. Распакуй архив.
2. Открой index.html в браузере — сайт будет работать локально.
3. Чтобы отправить девушке ссылку, загрузи всю папку love_site на статический хостинг (например, Netlify Drop или GitHub Pages).

В папке assets лежат ваша фотография и добавленный MP3.
Музыка запускается после нажатия «Открыть моё сердце», повторяется автоматически.
В правом нижнем углу есть кнопка включения/выключения музыки.

Важно: для публикации на хостинге загружай всю папку целиком, не один index.html.
